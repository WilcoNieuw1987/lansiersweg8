# Lansiersweg 8 — privé planning-hub

Een eenvoudige, statische pagina (één `index.html`) als overzicht voor de aankoop
van Lansiersweg 8 te Veenendaal: tijdlijn naar de overdracht (~feb 2027),
takenlijst (onthouden in je browser), woninggegevens en aandachtspunten.

Bewust **geen** bedragen, financiering of persoonsgegevens — de pagina is via de
Vercel-link openbaar bereikbaar.

## Lokaal bekijken
Open `index.html` in je browser. Geen build-stap nodig.

## Publiceren
Wijzigingen pushen naar `main`; Vercel deployt automatisch.
